# PEÑA CONNECT V2
CRM comercial PWA para Grupo Peña.

## Cambios
- Código único de cliente.
- Localidad.
- Foto del taller.
- Ubicación/enlace a Google Maps.
- Facturación mensual y anual 2025/2026.

- Eliminados de la interfaz marcas de tractores y tipo de cliente.
- Mantiene el mismo localStorage `pena-connect-v1` para conservar los datos existentes.
- Exportación JSON/CSV.
